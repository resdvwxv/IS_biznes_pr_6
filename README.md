# Практическая работа №6 — маршрутизация служебных заявок (вариант 6)

Небольшая логическая задача с ветвлениями и конечным набором решений.
Заявка автоматически направляется на один из маршрутов согласования в зависимости
от суммы, срочности, уровня риска и наличия персональных данных.

## Правила (в порядке приоритета)

| № | Условие | Маршрут |
|---|---------|---------|
| 1 | есть персональные данные | `SECURITY_REVIEW` |
| 2 | риск `HIGH` | `DIRECTOR_REVIEW` |
| 3 | сумма ≥ 500 000 | `FINANCE_REVIEW` |
| 4 | срочная и сумма < 325 000 (вариант 6) | `FAST_TRACK` |
| 5 | иначе | `STANDARD` |

Вариант 6: порог `FAST_TRACK` ниже финансового на 35 % (см. `DECISIONS.md`).

## Структура

```
src/ru/edu/pr03/
  ApprovalRoute.java   enum маршрутов
  RiskLevel.java       enum уровней риска
  ApprovalRouter.java  правило маршрутизации и проверка входных данных
  CsvRunner.java       чтение CSV и вывод результатов
  SelfCheck.java       самопроверка, граничные значения и ошибки
data/sample.csv        открытый набор данных
run_selfcheck.sh       сборка и запуск SelfCheck
```

Пакет называется `ru.edu.pr03` (так в исходном проекте); переименование не требуется.

## Сборка и запуск

```bash
./run_selfcheck.sh
```

Ожидаемый результат: `PASS`.

Запуск на данных из CSV (формат `amount;urgent;risk;personal`, разделитель `;`):

```bash
javac -encoding UTF-8 -d out $(find src -name "*.java")
java -cp out ru.edu.pr03.CsvRunner data/sample.csv
```

Для `sample.csv`: `FAST_TRACK`, `FINANCE_REVIEW`, `DIRECTOR_REVIEW`, `SECURITY_REVIEW`.
Некорректные строки не прерывают работу и выводятся как `ОШИБКА (строка N): ...`.
